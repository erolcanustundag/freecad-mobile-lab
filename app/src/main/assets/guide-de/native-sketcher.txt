Die Linie hat nun null Freiheitsgrade (DOF). Datum Profile 1 40 mm ändert ihre Länge. Rückgängig/Wiederholen verwenden FreeCAD-Transaktionen. -1,1 bezeichnet den Ursprung; Punkt 1 den Linienanfang, 2 das Ende und 3 den Kreismittelpunkt.

SketchCircle, SketchArc, SketchEllipse und SketchSpline erzeugen Originalgeometrie. Nach Sketch Curves: SketchSpline Curves 3 0,0;10,20;20,20;30,0 1,2,2,1. Die letzten Werte sind optionale positive rationale Gewichte.

Construction Profile 0 true macht eine Geometrie zur Konstruktion. MovePoint verwendet den nativen Löser. DeleteGeometry und DeleteConstraint verwenden aktuelle Indizes. Löschen kann verbleibende Geometrien neu nummerieren und abhängige Bedingungen entfernen. Prüfen Sie danach die Liste.

Bedingungen: Horizontal, Vertical, Coincident, Parallel, Perpendicular, Tangent, Equal, Distance, Radius, Diameter, Angle. Angle verwendet Grad; Datum akzeptiert Einheiten wie 30 deg oder 2 cm. Widersprüchliche oder redundante Änderungen werden zurückgerollt. Befehlsnamen bleiben sprachunabhängig.

Die Vorschau zeigt abgetastete Kurven in der lokalen XY-Ebene. Ziehen verschiebt, Pinch zoomt, Einpassen setzt zurück. Gold bedeutet normale Geometrie, Türkis Konstruktionsgeometrie. Bearbeiten erfolgt über Formulare/Befehle; die Vorschau ist kein Touch-Bedingungseditor.

Vor dem Schließen FCStd speichern und über die Dateiauswahl sichern. Unterstützte Sketcher/Part/App-Typen können erneut geöffnet werden. Allgemeine Desktop-Dokumente, vollständige Trimm-/Abrundungsabläufe, Spline-Griffe und PartDesign bleiben offen. Grenzen: 256 Geometrien/Bedingungen je Skizze, 64 Spline-Pole, 8.192 Vorschaupunkte. Android-Ausführung dieses Kandidaten bleibt ungeprüft.

EBENEN, ANHEFTUNG UND EXTERNE KANTEN
SketchPlane Profile XZ 0 0 10 setzt XY/XZ/YZ und Ursprung. SketchPlacement Profile 0 0 10 0 0 0 setzt XYZ in mm und Gier/Nick/Roll in Grad. Eine angeheftete Skizze zuerst mit SketchDetach lösen.

Add Solid Box, Sketch Attached, SketchLine Attached 0 0 10 0 und SketchAttach Attached Solid Face6 einzeln ausführen. SketchOffset Attached 0 0 2 0 0 0 setzt 2 mm Versatz zur Fläche. Änderungen an Solid.Height aktualisieren die Platzierung. SketchDetach Attached erhält die Weltplatzierung; Rückgängig stellt die Anheftung wieder her. Unterstützt wird eine einzelne ebene Fläche.

External Attached Solid Edge9 projiziert eine native Kante. Geometrieindizes beginnen bei -3, -4 usw. Constraint Attached Coincident 0 1 -3 1 und Constraint Attached Coincident 0 2 -3 2 binden die Endpunkte. Änderungen an Solid.Length aktualisieren die Linie. DeleteExternal Attached 0 löscht die erste Referenz und abhängige Bedingungen. Rückgängig/Wiederholen sowie FCStd erhalten native Abhängigkeiten. Externe Kanten sind magenta.

Maximal 64 externe Kanten. Fehlende, doppelte, zyklische oder zu Punkten kollabierende Referenzen und ungültige Änderungen werden zurückgerollt. Vor dem Löschen einer Quelle Anheftungen lösen und externe Referenzen entfernen. Aktuelle Flächen-/Kantennummern nach größeren Topologieänderungen prüfen. Schnitt-/Definitionsgeometrie, weitere Anheftungsmodi und vollständige Topologieabläufe sind noch offen.

NATIVES TRIMMEN / VERLÄNGERN / ABRUNDEN / TEILEN
SketchTrim Cut 0 10 0 entfernt das gewählte Stück zwischen Schnittpunkten. Ohne Schnittpunkte kann das native Trimmen die ganze Geometrie entfernen. Punkte verwenden skizzenlokales XY und müssen auf der aktuellen Kurve liegen.
SketchExtend Line 0 5 2 verlängert Endpunkt2 um5mm; -2 verkürzt um2mm. Endpunkte sind1/2. Nur Liniensegmente sind verfügbar. Maßbedingungen bleiben maßgeblich; der Solver kann die ursprüngliche Länge beibehalten.
Für Linien (0,0)-(20,0) und (20,0)-(20,20): SketchFillet Corner 0 1 18 0 20 2 2 erzeugt einen tangentialen2mm-Bogen und trimmt beide Linien. Zwei Linien mit gemeinsamem Endpunkt wählen; Punkte müssen auf ihnen liegen und der Radius kleiner als beide Längen sein.
SketchSplit Line 0 7 0 teilt am Punkt auf der Kurve und aktualisiert native Bedingungen. Indizes können sich ändern: Ergebnisliste prüfen. Rückgängig/Wiederholen und FCStd erhalten die Ergebnisse. Fehler rollen zurück. Weitere Kurvenabrundungen, Verlängerungsvarianten und Touch-Bearbeitung bleiben offen.

SPIEGELN, ANORDNUNGEN, SYMMETRIE UND REFERENZMASSE
SketchMirror Profile 0,1 Y spiegelt ausgewählte interne Geometrien an Y. X oder ein aktueller Linienindex sind ebenfalls möglich. Hilfsgeometriestatus und geeignete interne Bedingungen werden kopiert. Es entstehen Kopien ohne automatische Live-Spiegelverknüpfung; Symmetric-Bedingungen verbinden Punkte live.
SketchArray Rings 0 3 2 10 0 1 false erzeugt3 Spalten/2 Zeilen. Spalten folgen(10,0), Zeilen der im Uhrzeigersinn senkrechten Richtung(0,-10);1 skaliert den Zeilenabstand. true erzeugt native Abstands-Hilfslinien/Bedingungen. Indizes vor einer Datum-Änderung prüfen. Abstände steuern Positionen; Radien sind nicht automatisch gemeinsam, ein dauerhaftes Array-Feature entsteht nicht.
Constraint Profile Symmetric 0 1 1 1 -2 verbindet zwei Punkte symmetrisch zu Y.5 Werte: zwei Geometrie/Punkt-Paare und Achse.6 Werte: drei Punktpaare, zuletzt der Mittelpunkt. X/Y-Achsen sind-1/-2; Ursprung ist-1,1.
Driving Profile 1 false erzeugt ein Referenzmaß, das der gelösten Geometrie folgt. true stellt ein steuerndes Maß her. Referenz-Datumwerte können nicht direkt geändert werden. Bericht zeigt Steuerstatus und Roh-Einheiten(mm/Radiant).
1–32 eindeutige interne Indizes, bis64 Array-Zellen, innerhalb256 Geometrien/Bedingungen und±1Mmm. Hilfslinien und konservative Bedingungsreserven zählen zum Budget. Linien/Kreise/Bögen/Ellipsen/64-Pol-Splines werden kopiert. Koordinaten sind lokal XY. Rückgängig/Wiederholen, atomare Fehler und FCStd erhalten native Ergebnisse.

BEDINGUNGSWERKZEUGE (1.4)
Constraint Profile PointOnObject 0 1 -1 bindet Endpunkt 1 an die X-Achse. -2 bezeichnet Y; interne Indizes andere Kurven; -3/-4 projizierte externe Kanten. Punkt und Zielkurve müssen verschieden sein. Die native Beziehung begrenzt den Kurvenparameter nicht auf ein Liniensegment.
Constraint Profile DistanceX 0 -20 steuert den vorzeichenbehafteten horizontalen Linienversatz; DistanceY den vertikalen. Punkt zum Ursprung: DistanceX 0 1 -5. Zwischen zwei Punkten: DistanceY 0 1 1 2 10. Werte in Millimetern; Datum akzeptiert Einheiten. Koordinatenmaße unterstützen Referenzmodus.
Constraint Profile Block 0 fixiert eine interne Linie, einen Kreis, Bogen, eine Ellipse oder einen begrenzten Spline. Active Profile 0 false deaktiviert eine Bedingung ohne Löschen; true aktiviert sie. Aktivzustand und steuerndes/Referenzmaß werden getrennt angezeigt. Ein reaktivierter Block fixiert die aktuelle Geometrie, nicht eine frühere Lage. Widersprüche werden zurückgerollt. Große Orientierungsänderungen einer genau senkrechten Linie können eine native Singularität auslösen; widersprüchliche Bedingungen deaktivieren und einen Endpunkt leicht verschieben, dann erneut versuchen.
Inaktive Maße können mit Datum geändert werden; die Geometrie folgt erst nach erfolgreicher Aktivierung. Undo/Redo und FCStd erhalten die Modi. Nach dem Löschen aktuelle Indizes verwenden.

BENANNTE PROFILE (1.5)
ConstraintName Profile 0 RadiusValue vergibt einen eindeutigen Bezeichner bis64 Zeichen; Unicode wird unterstützt. Ein leerer Name in Anführungszeichen löscht ihn. ConstraintExpression Profile 0 Parameters.Width * 2 bindet ein aktives steuerndes Maß an einen nativen Ausdruck; leerer Text löscht ihn. Grenze512 Zeichen. Vor Datum den Ausdruck löschen. Einheiten- und Zyklusfehler werden zurückgerollt. SketchInfo Profile zeigt DOF, vollständige Einschränkung, Namen, Ausdrücke, Flags und Punktreferenzen ohne Historienänderung.
SketchExtrude Profile Solid 10 erstellt eine verknüpfte native Part-Extrusion entlang der Skizzennormalen; diese folgt Ebenenänderungen. SketchRevolve Profile Solid 360 0 0 0 0 1 0 erstellt eine Part-Rotation um eine Weltachse. Neue Profile müssen null DOF und genau einen gültigen geschlossenen Draht besitzen. Offene/mehrfache Drähte und ungültige Körper werden abgewiesen. Ergebnisnamen müssen neu sein. Quellenänderungen berechnen Abhängigkeiten neu, auch nach FCStd-Wiederherstellung. Abhängige Körper vor der Quellskizze löschen. Maße in mm, Rotationswinkel in Grad. Set Solid.LengthFwd 20 mm und Set Solid.Angle 180 deg ändern native Ausdehnungen. Part-Profilmodellierung, kein PartDesign-Body/Pad.

LOFT, REGELFLÄCHE, VERSATZ UND SPIEGELUNG (1.9)

Das Ergebnis muss ein gültiger geschlossener Volumenkörper bleiben. Null, kollabierte und ungültige Ergebnisse werden zurückgerollt. Kein Dickenwerkzeug mit entfernten ausgewählten Flächen.
PartMirror Solid Mirrored 0 0 0 1 0 0 spiegelt an einer Weltebene aus XYZ-Ursprung und einem von Null verschiedenen XYZ-Normalenvektor. Die Normale wird normiert; die Quelle bleibt verknüpft. Ohne geschlossene Volumenkörper wird Volumen null angezeigt: Integrale offener Flächen sind kein eingeschlossenes Volumen. Vollständige Desktop-Parität bleibt unvollständig.
