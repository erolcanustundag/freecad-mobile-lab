ORIGINALER FREECAD SKETCHER

Öffnen Sie das Dokumentlabor über den Wiederherstellungsbildschirm. Mit Neu erstellen Sie ein Dokument, dann Originaler Sketcher → Neue native Skizze. Formulare oder Befehlszeile bearbeiten die Skizze. Koordinaten und Längen verwenden Millimeter. Geometrie- und Bedingungsindizes beginnen bei 0.

Die Linie hat nun null Freiheitsgrade (DOF). Datum Profile 1 40 mm ändert ihre Länge. Rückgängig/Wiederholen verwenden FreeCAD-Transaktionen. -1,1 bezeichnet den Ursprung; Punkt 1 den Linienanfang, 2 das Ende und 3 den Kreismittelpunkt.

SketchCircle, SketchArc, SketchEllipse und SketchSpline erzeugen Originalgeometrie. Nach Sketch Curves: SketchSpline Curves 3 0,0;10,20;20,20;30,0 1,2,2,1. Die letzten Werte sind optionale positive rationale Gewichte.

Construction Profile 0 true macht eine Geometrie zur Konstruktion. MovePoint verwendet den nativen Löser. DeleteGeometry und DeleteConstraint verwenden aktuelle Indizes. Löschen kann verbleibende Geometrien neu nummerieren und abhängige Bedingungen entfernen. Prüfen Sie danach die Liste.

Bedingungen: Horizontal, Vertical, Coincident, Parallel, Perpendicular, Tangent, Equal, Distance, Radius, Diameter, Angle. Angle verwendet Grad; Datum akzeptiert Einheiten wie 30 deg oder 2 cm. Widersprüchliche oder redundante Änderungen werden zurückgerollt. Befehlsnamen bleiben sprachunabhängig.

Die Vorschau zeigt abgetastete Kurven in der lokalen XY-Ebene. Ziehen verschiebt, Pinch zoomt, Einpassen setzt zurück. Gold bedeutet normale Geometrie, Türkis Konstruktionsgeometrie. Bearbeiten erfolgt über Formulare/Befehle; die Vorschau ist kein Touch-Bedingungseditor.

Vor dem Schließen FCStd speichern und über die Dateiauswahl sichern. Unterstützte Sketcher/Part/App-Typen können erneut geöffnet werden. Allgemeine Desktop-Dokumente, Trimmen/Abrunden, Spline-Griffe und PartDesign bleiben offen. Grenzen: 256 Geometrien/Bedingungen je Skizze, 64 Spline-Pole, 8.192 Vorschaupunkte. Android-Ausführung dieses Kandidaten bleibt ungeprüft.

EBENEN, ANHEFTUNG UND EXTERNE KANTEN
SketchPlane Profile XZ 0 0 10 setzt XY/XZ/YZ und Ursprung. SketchPlacement Profile 0 0 10 0 0 0 setzt XYZ in mm und Gier/Nick/Roll in Grad. Eine angeheftete Skizze zuerst mit SketchDetach lösen.

Add Solid Box, Sketch Attached, SketchLine Attached 0 0 10 0 und SketchAttach Attached Solid Face6 einzeln ausführen. SketchOffset Attached 0 0 2 0 0 0 setzt 2 mm Versatz zur Fläche. Änderungen an Solid.Height aktualisieren die Platzierung. SketchDetach Attached erhält die Weltplatzierung; Rückgängig stellt die Anheftung wieder her. Unterstützt wird eine einzelne ebene Fläche.

External Attached Solid Edge9 projiziert eine native Kante. Geometrieindizes beginnen bei -3, -4 usw. Constraint Attached Coincident 0 1 -3 1 und Constraint Attached Coincident 0 2 -3 2 binden die Endpunkte. Änderungen an Solid.Length aktualisieren die Linie. DeleteExternal Attached 0 löscht die erste Referenz und abhängige Bedingungen. Rückgängig/Wiederholen sowie FCStd erhalten native Abhängigkeiten. Externe Kanten sind magenta.

Maximal 64 externe Kanten. Fehlende, doppelte, zyklische oder zu Punkten kollabierende Referenzen und ungültige Änderungen werden zurückgerollt. Vor dem Löschen einer Quelle Anheftungen lösen und externe Referenzen entfernen. Aktuelle Flächen-/Kantennummern nach größeren Topologieänderungen prüfen. Schnitt-/Definitionsgeometrie, weitere Anheftungsmodi und vollständige Topologieabläufe sind noch offen.
