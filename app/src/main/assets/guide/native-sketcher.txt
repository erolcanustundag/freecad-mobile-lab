ORIGINAL FREECAD SKETCHER

Open the Document Lab from the recovery screen. Select New to create a document, then Original Sketcher → New native sketch. Use the form or the command bar. Coordinates and constraint lengths below use millimetres. Geometry and constraint indices start at 0.

Try this exact sequence:
NewDoc SketchModel
Sketch Profile
SketchLine Profile 0 0 30 0
Constraint Profile Horizontal 0
Constraint Profile Distance 0 30
Constraint Profile Coincident 0 1 -1 1
SketchPreview Profile
Save SketchModel.FCStd

The line now has zero degrees of freedom (DOF). Change its length with Datum Profile 1 40 mm. Undo and Redo use FreeCAD transactions. -1,1 references the sketch origin; point 1 is a line's start, 2 its end and 3 a circle's centre.

SketchCircle, SketchArc, SketchEllipse and SketchSpline add original geometry. A spline example is SketchSpline Curves 3 0,0;10,20;20,20;30,0 1,2,2,1 after creating Sketch Curves. Last values are optional positive rational weights.

Construction Profile 0 true makes an entity construction-only. MovePoint uses the native solver. DeleteGeometry and DeleteConstraint use current zero-based indices; deletion may renumber remaining entities and remove dependent constraints. Check the displayed entity list afterward.

Constraint kinds: Horizontal, Vertical, Coincident, Parallel, Perpendicular, Tangent, Equal, Distance, Radius, Diameter, Angle. Angle creation uses degrees; Datum accepts explicit units such as 30 deg or 2 cm. Conflicting/redundant edits are rejected and rolled back. The Python console can inspect the original Sketcher API.

SketchPreview displays sampled local XY curves. Drag to pan, pinch to zoom, Fit to reset. Gold is regular geometry, cyan is construction geometry, magenta is external reference geometry. This view is a preview; edit via forms/commands. It is not a touch constraint editor.

Save FCStd before closing. Export it through the file picker for backup. Supported Sketcher/Part/App types can reopen in the native lab. Arbitrary desktop documents, full trim/fillet workflows, spline pole handles, PartDesign and other workbench UI remain pending. Limits: 256 entities/constraints per sketch, 64 spline poles, 8,192 display points. Android execution of this candidate is pending.

PLANES, FACE ATTACHMENT AND EXTERNAL EDGES
SketchPlane Profile XZ 0 0 10 selects XY/XZ/YZ and XYZ origin in mm. SketchPlacement Profile 0 0 10 0 0 0 uses XYZ mm then yaw/pitch/roll degrees. Detach a face-attached sketch before changing its free placement.

Enter individually: Add Solid Box; Sketch Attached; SketchLine Attached 0 0 10 0; SketchAttach Attached Solid Face6. SketchOffset Attached 0 0 2 0 0 0 adds a 2 mm face-relative offset. Changing Solid.Height updates the attachment. SketchDetach Attached retains world placement; Undo restores the support. Only one planar FlatFace support is exposed.

External Attached Solid Edge9 adds an upstream projected edge. Its solver index is -3, then -4, etc. Constraint Attached Coincident 0 1 -3 1 and Constraint Attached Coincident 0 2 -3 2 link endpoints; changing Solid.Length updates the line. DeleteExternal Attached 0 deletes reference zero and its dependent constraints. Undo/Redo and FCStd preserve native dependencies. External preview edges are magenta.

Up to 64 external edges. Missing, cyclic, duplicate or collapsed projections and invalid changes roll back. Detach supports/remove external references before deleting a source. Face/Edge numbers refer to current native lists; inspect references after major topology edits. Intersection/defining external geometry, other attachment modes and full topology workflows remain pending.

NATIVE TRIM / EXTEND / FILLET / SPLIT
SketchTrim Cut 0 10 0 removes the picked span between intersections. With no intersections, original trim can remove the entire entity. Picks use sketch-local XY and must lie on the current curve.
SketchExtend Line 0 5 2 extends endpoint2 by5mm; -2 shortens by2mm. Endpoints are1/2. This tool exposes line segments only. Driving dimensions remain authoritative; the solver may preserve their original length.
For lines (0,0)-(20,0) and (20,0)-(20,20): SketchFillet Corner 0 1 18 0 20 2 2 creates a2mm tangent arc and trims both lines. Only a common-endpoint pair of lines is exposed; picks must be on them and radius smaller than both lengths.
SketchSplit Line 0 7 0 splits at a point on the curve, preserving native constraint updates. Geometry/constraint indices can change: inspect the resulting list. Undo/Redo and FCStd preserve native results. Errors roll back. Broader curved-corner fillets, extension variants and touch editing remain pending.

MIRROR, ARRAYS, SYMMETRY AND REFERENCE DIMENSIONS
SketchMirror Profile 0,1 Y mirrors selected internal geometry across Y; X chooses X, or enter a current line index. Construction flags and eligible internal constraints are copied. This creates mirrored copies, not an automatic live mirror relation. Use Symmetric constraints for live point relations.
SketchArray Rings 0 3 2 10 0 1 false creates3 columns and2 rows: columns follow (10,0), rows follow the clockwise perpendicular (0,-10). The scale1 multiplies the row pitch. true adds native construction spacing lines and constraints; inspect their indices before changing a Datum. Spacing controls positions, not automatic shared radii or a persistent array feature tree.
Constraint Profile Symmetric 0 1 1 1 -2 links two points about the Y axis. Use5 arguments (two geometry/point pairs and an axis) or6 (three point pairs, the last being the centre). X/Y axes are -1/-2; origin is -1,1.
Driving Profile 1 false makes a dimensional constraint a reference measurement; its value follows solved geometry. Driving Profile 1 true restores a driving dimension. Reference datums cannot be edited directly. The report shows driving flags and raw units (mm or radians).
Select1–32 unique internal indices, up to64 array cells, within256 entities/constraints and±1Mmm. Budget checks include spacing helpers and conservative constraint reserves. Copy tools accept current line/circle/arc/ellipse/64-pole spline entities. New commands use sketch-local XY. Undo/Redo, atomic errors and FCStd preserve native results.

CONSTRAINT TOOLS (1.4)
Constraint Profile PointOnObject 0 1 -1 puts line endpoint 1 on the X axis. Use -2 for Y, an internal curve index for another curve, or -3/-4/etc. for projected external edges. The source point and target curve must differ. This is a native curve relation, not a clamped segment parameter.
Constraint Profile DistanceX 0 -20 constrains signed line displacement; DistanceY is vertical. For a point relative to the origin use DistanceX 0 1 -5. For two points use DistanceY 0 1 1 2 10. Values are signed millimetres; Datum accepts units. Reference mode also works for coordinate dimensions.
Constraint Profile Block 0 fixes an internal line, circle, arc, ellipse or bounded spline. Redundant/conflicting fixes roll back. Active Profile 0 false disables a current constraint without deleting it; true reactivates it. State reports active independently of driving/reference. A reactivated Block fixes current geometry; it is not a stored earlier pose. Reactivating a contradictory condition is rejected. Native solver singularities can reject a large orientation change from a precisely perpendicular line; disable conflicting conditions and move an endpoint slightly before retrying.
Disabled dimensions can be edited with Datum; their value is applied to geometry only on successful activation. Undo/Redo and FCStd preserve constraint modes. Always use current zero-based indices after deletion.

NAMED PROFILES (1.5)
ConstraintName Profile 0 RadiusValue assigns a unique identifier (up to64 characters, Unicode supported). Use an empty quoted name to clear. ConstraintExpression Profile 0 Parameters.Width * 2 binds an active driving dimension to a native expression; empty quoted text clears it. Formula text is limited to512 characters. Clear an expression before Datum; native dependencies/cycles and unit errors use transactional rollback. SketchInfo Profile inspects solved DOF, fully-constrained state, named dimensions, expressions, flags and current point references without a history edit.
SketchExtrude Profile Solid 10 creates a native linked Part extrusion along the sketch normal. The normal follows plane changes. SketchRevolve Profile Solid 360 0 0 0 0 1 0 creates a native linked Part revolution using a world-space axis origin/vector. A new profile must have zero DOF and one valid closed wire; open, multiple-wire and invalid/self-intersecting solid results are rejected. Solid names must be new. Source edits recompute dependants, including after FCStd restoration. Remove dependent solids before their source sketch. Dimensions are mm and revolution amounts are degrees. Set Solid.LengthFwd 20 mm and Set Solid.Angle 180 deg edit native extents. This is Part profile modelling, not a PartDesign Body/Pad workflow.

SOLID CONTROLS (1.6)
ExtrusionSettings Solid 10 5 false false sets forward/reverse mm extents, symmetry and reversal. Symmetry splits forward depth equally about the profile and ignores reverse depth, as the native feature does. RevolutionSettings Solid 180 0 0 0 0 1 0 true sets degrees, world axis origin/vector and symmetry. Direction vectors are normalized and must be nonzero.
PartPlacement Solid 3 4 5 90 0 0 sets world XYZ and yaw/pitch/roll degrees on supported native Part objects. Native shape placement is preserved by Undo/Redo/FCStd. ShapeInfo Solid reports exact native volume(mm³), area(mm²), unique boundary edge lengths(mm), bounds(mm) and a solid centroid for one-solid shapes. Wire/multi-solid results have no reported solid centroid. Inspection is read-only; limited to2000 faces/10000 edges. This is a geometric centroid, not a density-weighted material mass calculation.

NATIVE FINISHING (1.7)
PartFillet Source Rounded 1,2 1 and PartChamfer Source Beveled 1 1 create linked native Part features. Edge numbers start at1, with1–32 unique current edges. Radius/equal chamfer distances use mm. Source edits recompute the feature; topology-changing edits can invalidate selection and roll back. Remove dependent finishing features before the source.
PartRefine Source Refined makes an explicitly labelled refinement snapshot using the native remove-splitter operation. It removes eligible coplanar seams and preserves native geometry; source edits do not update this snapshot. PartSection Source Tool Section creates a linked native intersection section between different supported Part shapes. Empty results roll back. Sections are wire geometry: use ShapeInfo and STEP export; the face/solid triangle preview does not display wires. Limits remain2000 faces/10000 edges and±1Mmm bounds. Refinement is not mesh smoothing or surface reconstruction.

SECTIONS AND EDGE INSPECTION (1.8)
SectionPlane Solid Slice 0 0 5 0 0 1 100 creates a native finite Part plane centred at world XYZ (0,0,5), with normal (0,0,1) and size100mm, and a linked native section. Slice_Plane is the editable helper; PartPlacement changes its world placement. The plane has local UV bounds0..size; its placement offsets those bounds about the requested centre. The source and helper stay as dependencies. Empty/invalid sections and out-of-bounds helper planes roll back together.
WirePreview Slice samples actual world-space native edges for display. Drag to orbit, pinch to zoom, two fingers to pan; Fit resets the view. Edge numbers are current1-based indices. At most128 edges/8192 points; straight edges use2 points, curves65. Tiny/pole edges at or below1e-7mm are skipped for drawing. Sampling changes display detail only; native geometry and STEP exports retain their exact curves. Touch gestures have not been independently tested on Android.
ElementInfo Solid Edge1 reports exact length, bounds, raw curve parameter range and endpoint coordinates. ElementInfo Solid Face1 reports native area/surface type, area centroid and a point/normal evaluated at the middle of the surface parameter range. The area centroid need not lie on the surface; the evaluated point need not lie within every trimmed face. Units are mm/mm²; curve/UV parameters retain native units. Below-tolerance edges report that flag rather than claiming they are topologically degenerate.
FinishSettings Rounded 1,2 2 updates current edge selections and equal radius/distance in mm on a native fillet/chamfer. Native recompute, Undo/Redo and FCStd preserve the edit. Use1–32 unique current1-based edges. This is not a guarantee of stable selections across arbitrary topology changes. Inspect and retry if native geometry fails.

LOFT, RULED SURFACE, OFFSET AND MIRROR (1.9)
PartLoft Loft ProfileA,ProfileB true false creates a linked native Part loft: result name, comma-separated2–16 unique single-wire profiles, solid flag, ruled flag. Solid lofts need closed profiles; false allows open wire profiles. Profiles remain editable native dependencies. Closed last-to-first loft mode is not exposed. Native failure rolls back. Use bounded supported wire geometry, at most256 edges per profile. This is Part loft modelling, not PartDesign AdditiveLoft.
PartRuled Surface Lower Edge1 Upper Edge1 creates a native ruled surface between two current edges. Selections are1-based native edge names, may belong to the same object if they differ, and must be nonzero. Native source edits recompute the surface; topology changes can invalidate references. General surface blends/continuity controls are not included.
PartOffset Solid Offset 1 creates a linked native solid offset in mm with intersection joins. Negative amounts offset inward; the result must remain one valid closed solid. Set Offset.Value 2 edits the amount. Zero, collapse and invalid geometry roll back. This is an offset of all faces, not a thickness tool with selected removed faces.
PartMirror Solid Mirrored 0 0 0 1 0 0 mirrors about a world plane given by origin XYZ and nonzero normal XYZ. The normal is normalized; source geometry remains linked and editable. Wires and surfaces are supported when the resulting native shape is valid. This is native feature mirroring, distinct from copied sketch geometry.
Undo/Redo, native FCStd and STEP preserve supported outputs; profiles/sources cannot be deleted while their dependants remain. Shapes stay within±1Mmm/2000faces/10000edges. Native algorithms can allocate or take time before result limits are checked; Android memory/lifecycle performance remains unmeasured. ShapeInfo and document reports return null volume for shapes without closed solids: open-face volume integrals are not enclosed volume. Full desktop Part/PartDesign/Rhino parity remains incomplete.

Loft/ruled BSpline inputs are limited to64 poles per selected curve.
