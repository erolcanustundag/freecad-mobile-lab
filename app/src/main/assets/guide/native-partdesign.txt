Original PartDesign · Body, Pad and Pocket

Open Document lab → New → Original PartDesign. These are original FreeCAD 1.1.4 features with native dependencies, not baked mobile solids. The main CAD workspace remains a separate model.

Quick command example (run each line separately):
NewDoc BodyDemo
Body Body
BodySketch Body Profile
SketchCircle Profile 0 0 10
Constraint Profile Block 0
Pad Body Profile Pad 10
BodySketch Body CutProfile
SketchCircle CutProfile 0 0 2
Constraint CutProfile Block 0
SketchPlane CutProfile XY 0 0 10
Pocket Body CutProfile Pocket 2
Preview Body 0.2
BodyInfo Body
Save BodyDemo.FCStd
ExportStep Body BodyDemo.step

Pad creates a radius10, height10 cylinder. Pocket removes a radius2, depth2 bore from its top. Lengths in Pad/Pocket commands use mm. Set Pad.Length 2 cm accepts units; dependent features recompute. Undo and Redo use original document history.

BodySketch BODY NAME creates a new owned sketch or adopts an unused unowned original sketch. Profiles must contain one valid closed wire. Origin axes/planes/point are generated and protected. BodyFrom SOLID BODY links an independent native solid through original FeatureBase; changes to the source update the Body.

BodyTip Body Pad selects an earlier owned solid as the Body result. Later features remain in history. Before appending or removing a feature, select the last solid Tip. RemoveBodyFeature Body Pocket removes only the last Pad/Pocket when no other feature or sketch depends on it; its profile remains. Undo restores the feature and Tip.

Current limits: one connected closed solid per Body; forward/reverse/symmetric Length Pad/Pocket, one-sided native ThroughAll/planar UpToFace Pocket; positive length up to1,000,000mm; at most1,000 document objects including seven origin frames plus origin and Body; profile up to256 edges; feature up to1,024 faces. Pocket must remove material and retain one solid. Face names may change after upstream edits; inspect selections again.

PartDesign patterns, dress-up features, arbitrary history reordering, more than two loft profiles/multiple solids, other extent modes, Gui and full workbench restoration remain pending. Android device execution for this version is not yet verified. Save before leaving; documents are local and the app has no network permission.

1.14 · Revolutions, grooves and two-profile lofts
BodyRevolve BODY PROFILE NAME ANGLE H|V rotates a closed owned sketch about its horizontal H or vertical V axis. BodyGroove uses the same inputs to remove material from the last Body solid. Angles are forward, one-sided, greater than0 and at most360degrees. Set Revolved.Angle 180 deg updates the native feature. Other directions/extent modes and arbitrary external axes remain pending.

For a ring section: create a Body and owned sketch Radial; draw a closed rectangle with corners(10,0),(12,0),(12,5),(10,5). Run BodyRevolve Body Radial Revolved 360 V. A separate radius0.3 circle centred at(11,2), owned by the same Body, can cut a toroidal groove with BodyGroove Body Cut Grooved 360 V.

BodyAddLoft BODY LOWER UPPER NAME and BodySubLoft BODY LOWER UPPER NAME use exactly two different, unused, closed sketches owned by that Body. They create original ruled lofts; Closed and arbitrary multi-section/smooth loft modes are not exposed. For a cone frustum, use Lower circle radius2 atz0 and Upper circle radius1 atz5 (SketchPlane Upper XY 0 0 5). Run BodyAddLoft Body Lower Upper Loft. A second pair of radius0.4/radius0.2 sketches atz0/z5 removes a tapered bore with BodySubLoft Body BoreLower BoreUpper Bore. Subtractive tools must remove real material and retain one connected solid. Section geometry/placement edits update the native feature.

These features share BodyInfo, BodyTip, safe last-feature removal, Undo/Redo, FCStd and STEP workflows. Pad/Pocket/Revolution/Groove/Loft ownership and protected origin lists are checked before restoration. Native topology names can change; inspect references after edits. Android device execution remains unverified for1.14.

1.15 · Original Body finishing
The tools use the last owned solid Tip. Inspect current elements with ElementInfo; source edits may change names. Numbers start at1; comma lists contain unique numbers.
BodyFillet BODY NAME EDGES RADIUS_MM
BodyChamfer BODY NAME EDGES SIZE_MM
BodyDraft BODY NAME FACES NEUTRAL_FACE ANGLE_DEG
BodyThickness BODY NAME OPEN_FACES WALL_MM

Example, each line separately:
NewDoc Finishing
Add Stock Box
BodyFrom Stock Body
BodyFillet Body Rounded 1 1
Set Rounded.Radius 2 mm
Undo
Preview Body 0.2

For separate10mm boxes/Bodies: BodyChamfer BevelBody Beveled 1 1 creates an equal-distance chamfer. BodyDraft DraftBody Drafted 1 5 5 drafts face1 by5degrees, using face5 as neutral plane and the original Body local Z axis. BodyThickness ShellBody Hollow 6 1 opens face6 and creates an inward1mm skin wall.

Limits:1–32 explicit fillet/chamfer edges;1–16 draft/open faces; positive amounts below the minimum source extent. Inward skin/arc thickness is below half the minimum extent, retains a face and removes actual interior material. Draft is planar, positive up to45degrees, with a different neutral plane perpendicular to local Z. Failures roll back. Unit edits, source updates, Undo/Redo, safe removal, FCStd and STEP preserve supported history. Move the whole Body; member feature placement follows its history. Api PartDesign and the Python console expose the original module. Other modes, arbitrary pull axes, variable radii, patterns, Gui and full workbench qualification remain pending. Android1.15 execution is not yet verified.

1.16 · Original Body patterns
BodyMirror BODY NAME XY|XZ|YZ
BodyLinear BODY NAME COUNT EXTENT_MM X|Y|Z
BodyPolar BODY NAME COUNT ANGLE_DEG X|Y|Z
BodyScaled BODY NAME COUNT FACTOR

Start from one last owned additive Pad/Revolution/AdditiveLoft, with up to64faces/256edges. Patterns use original Features mode and whole original Body origin axes/planes. Counts include the original and are bounded2–16 before recomputation. Linear is one forward total extent; Polar is forward total angle up to360degrees; Scaled grows from1 to a factor greater than1 and at most4 about the native source centre. Copies must form one connected solid. Spacing, second directions, multiple sources, subtractive/dress-up/pattern sources and other modes remain pending.

For a10mm rectangular Pad occupying x0–10/y0–10/z0–10: BodyMirror Body Mirrored XZ gives2000mm3; on separate identical Bodies BodyLinear Body Linear 2 8 X gives1800, BodyPolar Body Polar 4 360 Z gives4000, and BodyScaled Body Scaled 2 2 gives8000. These are native unions, not summed overlapping volumes. Set Linear.Length 1 cm, Set Polar.Angle 270 deg, Set Scaled.Factor 3 and Set Linear.Occurrences 3 update original features. Tip/history/source updates/rollback/FCStd/STEP are supported. Physical Android1.16 execution remains unverified.

NATIVE EXTRUSION EXTENTS (1.17)
Pad Body Profile ReversePad 10 reverse
Pad Body Profile SymmetricPad 10 symmetric
Pocket Body CutProfile ReverseCut 4 reverse
Pocket Body CutProfile SymmetricCut 8 symmetric
PocketThrough Body CutProfile Through forward
PocketFace Body CutProfile Stopped Face5 forward

Use a separate unused owned sketch for each feature; the examples are alternatives. Pad grows along the sketch normal, Pocket cuts opposite it; reverse flips that direction. Symmetric uses half the total length on each side. Through-all uses original FreeCAD Type=ThroughAll and cuts in the selected direction; place the sketch on or beyond the entry face. Face stopping uses original UpToFace on one planar face of the preceding owned Body solid, parallel to the sketch plane and ahead in the cut direction. Inspect source FaceN with ElementInfo before cutting. The native face link stays in the feature history; topology changes can invalidate it and are rejected. Both cuts must retain one valid solid and remove material.
Set Length with units for length extents. Set Reversed true/false for one-sided extents; invalid/no-removal direction edits roll back. Through/face extents have no editable Length. Two sides, taper, offset, custom vectors, curved stopping faces, other stopping modes and UpToShape and arbitrary external stopping references remain pending.

ADDITIONAL NATIVE EXTENTS (1.18)
PadFace Body AddProfile ToFace Face6 forward
PadLast Body AddProfile ToLast forward
PocketFirst Body CutProfile ToFirst forward
PadTwo Body Profile TwoSides 4 6
PocketTwo Body CutProfile TwoCuts 2 3

Each example uses a separate unused owned sketch and the current last solid Tip. PadFace links a planar face of the preceding owned solid, parallel to the sketch and ahead in its extrusion direction. Unlike Pocket, forward Pad follows the positive sketch normal. PadLast uses original UpToLast and PocketFirst uses original UpToFirst; the source is bounded to64faces/256edges and the native kernel chooses the stop. Stopping Pad must add material and remain connected; Pocket must remove material and retain one solid. Invalid/no-op/disconnected changes roll back. Native named face links may be invalidated by topology edits.
Two sides uses original SideType=Two sides, Type/Type2=Length, separate positive Length and Length2, total at most1,000,000mm. Direction is fixed: Length follows the feature's default direction (Pad positive normal; Pocket negative normal), Length2 uses the opposite direction. Set TwoSides.Length2 1 cm edits the second side with units. Symmetric retains its previous meaning of one total length split equally. Stopping extents have no editable Length. Arbitrary second-side stopping, taper/offset/custom vectors, curved/external explicit stopping references, PadUpToFirst and UpToShape remain pending.

Native pipe and helix tools (1.19)
BodyAddPipe BODY PROFILE PATH Edge1 NAME
BodySubPipe BODY PROFILE PATH Edge1 NAME
BodyAddHelix BODY PROFILE NAME PITCH HEIGHT
BodySubHelix BODY PROFILE NAME PITCH HEIGHT
Use separate unused sketches owned by the same Body. A pipe section is one circle, centered at the path start and perpendicular to its tangent. The path is one line or circular arc (at most 180 degrees; path radius greater than twice the section radius), selected as Edge1. Native Standard/Transformed/Constant mode retains both sketch links.
For helices, put one circle in the Body XZ plane, entirely on positive X; its center X is the coil radius. The original Body Z axis is retained. Positive pitch must exceed the section diameter, height/pitch must not exceed 16 turns, and the cone angle is zero. Set Helix.Pitch 4 mm or Set Helix.Height 9 mm to edit dimensions. Source sketches cannot contain external references or expressions in this bounded scope.
Subtractive tools need a preceding solid. Additive tools must add material and all results must remain a closed single solid. Stock has a 64-face/256-edge budget. Use the last Tip to append/remove. Controls are in Original PartDesign. General sections, multi-edge or auxiliary paths, twist laws, conical/left-handed helices and other modes remain pending.

Original Hole tools (1.20)
BodyHole BODY PROFILE NAME DIAMETER DEPTH
BodyHoleThrough BODY PROFILE NAME DIAMETER
BodyCounterbore BODY PROFILE NAME DIAMETER DEPTH HEAD_DIAMETER HEAD_DEPTH
BodyCountersink BODY PROFILE NAME DIAMETER DEPTH HEAD_DIAMETER
Use one unused owned circle sketch in a Body XY plane facing +Z, over the last solid Tip. The circle center locates the hole; Hole.Diameter sets its actual diameter independently of the sketch radius. The native hole cuts toward -Z. Flat blind and through-all holes, custom cylindrical counterbores and 90degree countersinks are supported. ThroughAll cuts all material below the profile plane; move the profile plane to the stock top after increasing stock height.
Set Hole.Diameter 3 mm, Hole.Depth 5 mm, Bore.HoleCutDiameter 6 mm or Bore.HoleCutDepth 2 mm. Through-all Depth and countersink angle/depth are read-only. Head diameter must exceed hole diameter. Counterbore head depth, or the derived 90degree countersink depth, must be smaller than the main depth. Source stock is limited to64faces/256edges; positive bounded dimensions, actual material removal, one closed solid, owned references and history are required. Threading, modelled threads, tapered/angled drill points, counterdrill, reverse and other modes remain pending.

Original Datum construction tools (1.21)
BodyPlane BODY NAME DISPLAY_LENGTH DISPLAY_WIDTH
BodyAxis BODY NAME DISPLAY_LENGTH
BodyPoint BODY NAME
BodyFrame BODY NAME
DatumPose BODY DATUM X Y Z YAW PITCH ROLL
BodySketchDatum BODY DATUM SKETCH
DatumInfo DATUM
DatumPreview DATUM
RemoveDatum BODY DATUM
SketchDetach SKETCH

Datums are original non-solid Body members. A plane or coordinate system can drive a whole owned sketch through original ObjectXY AttachmentSupport. BodySketchDatum creates a sketch or attaches an unused owned sketch. Draw and constrain geometry in local XY, then use Pad or other qualified tools. Moving the Datum updates the attached sketch and its native model. Free SketchPlane/SketchPlacement edits are blocked while attached; SketchDetach retains the current placement and removes the support link. RemoveDatum requires no remaining dependents.
DatumPose uses Body-local millimetres and yaw/pitch/roll degrees. DatumInfo and finite viewport guides use native world placement, including Body movement. Plane length/width and axis length are display-guide dimensions only, editable with Set WorkPlane.Length 2 cm. Original planes/axes remain mathematically unbounded. Point/frame crosshairs and axes are display guides, never replacement solids. Construction objects have no material volume, mesh, face/edge measurements or STEP export; export a driven solid instead. The axis's derived infinite-edge cache is transient so the original native constructor recreates it when reopening FCStd.
Limits:64Datums and64ObjectXY-attached sketches, guide dimensions up to10,000mm, finite world coordinates within1,000,000mm, one whole same-Body plane/frame support, no Datum mapping or offsets, no external geometry/expressions in attached sketches. Existing FlatFace workflows remain available separately. Native attachment modes, arbitrary support/axis/point attachments and advanced Datum features remain pending.

1.22 — native support-driven construction
DatumAttach BODY DATUM SOLID ELEMENT attaches a Plane to one planar FaceN, an Axis to one straight EdgeN, or a Point to one VertexN on an original solid in the same Body. The native FlatFace/Tangent/Vertex link follows source changes. Sources are limited to64faces/256edges/512vertices; cycles, foreign Bodies and curved supports are rejected. Coordinate systems retain manual placement. DatumDetach BODY DATUM preserves the current pose; detach before DatumPose.
SketchOffset SKETCH X Y Z YAW PITCH ROLL now also edits original ObjectXY offsets on an owned Datum plane/frame. Translations are mm and rotations degrees; the original source frame and offset compose before dependent geometry checks. Offsets must keep all geometry within the coordinate budget and the resulting solid valid. External geometry, expressions and general attachment modes remain pending. Use the PartDesign menu for touch forms and DatumInfo/DatumPreview to inspect references and finite guides.

1.23 — original Body box and cylinder features
BodyAddBox BODY NAME LENGTH WIDTH HEIGHT [X Y Z YAW PITCH ROLL]
BodySubBox BODY NAME LENGTH WIDTH HEIGHT [X Y Z YAW PITCH ROLL]
BodyAddCylinder BODY NAME RADIUS HEIGHT [X Y Z YAW PITCH ROLL]
BodySubCylinder BODY NAME RADIUS HEIGHT [X Y Z YAW PITCH ROLL]
BodyPrimitivePose BODY FEATURE X Y Z YAW PITCH ROLL
Dimensions and translations use mm; rotations use degrees. These are original linked PartDesign features with BaseFeature history. Append at the last solid Tip. An additive primitive must add material and remain one connected solid; a subtractive primitive must remove material and retain one closed solid. A cut needs existing stock. Use Set FEATURE.Height 2 cm (and Length/Width/Radius as applicable) for native quantity editing. The PartDesign menu provides creation and placement forms.
There are at most 64 primitives per document, bounded world coordinates within 1,000,000 mm and source geometry up to 64 faces/256 edges. Cylinders use the full 360 degrees with straight default ends. Placement is manual; expressions, mapped/partial/tapered primitives and other primitive types remain pending. Native support-driven Datum references can use these original solids. Save FCStd to keep dimensions, source links and history; STEP exports the resulting solid.

Original Body cones and spheres
Full cones accept nonnegative Radius1/Radius2 (at least one positive) and positive Height. Equal radii and zero-radius apices are supported. Full spheres use positive Radius. Use BodyAddCone/BodySubCone BODY NAME R1 R2 HEIGHT and BodyAddSphere/BodySubSphere BODY NAME RADIUS, optionally followed by X Y Z YAW PITCH ROLL. Set accepts units; BodyPrimitivePose moves these original features. Additions must add connected material; cuts must remove material and retain one closed solid. Angles, expressions and attached mapping remain restricted.
