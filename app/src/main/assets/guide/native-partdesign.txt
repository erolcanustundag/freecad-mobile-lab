Original PartDesign · Body, Pad and Pocket

Open Document lab → New → Original PartDesign. These are original FreeCAD 1.1.4 features with native dependencies, not baked mobile solids. The main CAD workspace remains a separate model.

Quick command example (run each line separately):

Pad creates a radius10, height10 cylinder. Pocket removes a radius2, depth2 bore from its top. Lengths in Pad/Pocket commands use mm. Set Pad.Length 2 cm accepts units; dependent features recompute. Undo and Redo use original document history.

BodySketch BODY NAME creates a new owned sketch or adopts an unused unowned original sketch. Profiles must contain one valid closed wire. Origin axes/planes/point are generated and protected. BodyFrom SOLID BODY links an independent native solid through original FeatureBase; changes to the source update the Body.

BodyTip Body Pad selects an earlier owned solid as the Body result. Later features remain in history. Before appending or removing a feature, select the last solid Tip. RemoveBodyFeature Body Pocket removes only the last Pad/Pocket when no other feature or sketch depends on it; its profile remains. Undo restores the feature and Tip.

Current limits: one connected closed solid per Body; forward/reverse/symmetric Length Pad/Pocket, one-sided native ThroughAll/planar UpToFace Pocket; positive length up to1,000,000mm; at most1,000 document objects including seven origin frames plus origin and Body; profile up to256 edges; feature up to1,024 faces. Pocket must remove material and retain one solid. Face names may change after upstream edits; inspect selections again.

PartDesign patterns, dress-up features, arbitrary history reordering, more than two loft profiles/multiple solids, other extent modes, Gui and full workbench restoration remain pending. Android device execution for this version is not yet verified. Save before leaving; documents are local and the app has no network permission.

1.14 · Revolutions, grooves and two-profile lofts
BodyRevolve BODY PROFILE NAME ANGLE H|V rotates a closed owned sketch about its horizontal H or vertical V axis. BodyGroove uses the same inputs to remove material from the last Body solid. Angles are forward, one-sided, greater than0 and at most360degrees. Set Revolved.Angle 180 deg updates the native feature. Other directions/extent modes and arbitrary external axes remain pending.

For a ring section: create a Body and owned sketch Radial; draw a closed rectangle with corners(10,0),(12,0),(12,5),(10,5). Run BodyRevolve Body Radial Revolved 360 V. A separate radius0.3 circle centred at(11,2), owned by the same Body, can cut a toroidal groove with BodyGroove Body Cut Grooved 360 V.

BodyAddLoft BODY LOWER UPPER NAME and BodySubLoft BODY LOWER UPPER NAME use exactly two different, unused, closed sketches owned by that Body. They create original ruled lofts; Closed and arbitrary multi-section/smooth loft modes are not exposed. For a cone frustum, use Lower circle radius2 atz0 and Upper circle radius1 atz5 (SketchPlane Upper XY 0 0 5). Run BodyAddLoft Body Lower Upper Loft. A second pair of radius0.4/radius0.2 sketches atz0/z5 removes a tapered bore with BodySubLoft Body BoreLower BoreUpper Bore. Subtractive tools must remove real material and retain one connected solid. Section geometry/placement edits update the native feature.

These features share BodyInfo, BodyTip, safe last-feature removal, Undo/Redo, FCStd and STEP workflows. Pad/Pocket/Revolution/Groove/Loft ownership and protected origin lists are checked before restoration. Native topology names can change; inspect references after edits. Android device execution remains unverified for1.14.

1.15 · Original Body finishing
The tools use the last owned solid Tip. Inspect current elements with ElementInfo; source edits may change names. Numbers start at1; comma lists contain unique numbers.
BodyFillet BODY NAME EDGES RADIUS_MM
BodyChamfer BODY NAME EDGES SIZE_MM
BodyDraft BODY NAME FACES NEUTRAL_FACE ANGLE_DEG
BodyThickness BODY NAME OPEN_FACES WALL_MM

Example, each line separately:
NewDoc Finishing
Add Stock Box
BodyFrom Stock Body
BodyFillet Body Rounded 1 1
Set Rounded.Radius 2 mm
Undo
Preview Body 0.2

For separate10mm boxes/Bodies: BodyChamfer BevelBody Beveled 1 1 creates an equal-distance chamfer. BodyDraft DraftBody Drafted 1 5 5 drafts face1 by5degrees, using face5 as neutral plane and the original Body local Z axis. BodyThickness ShellBody Hollow 6 1 opens face6 and creates an inward1mm skin wall.

Limits:1–32 explicit fillet/chamfer edges;1–16 draft/open faces; positive amounts below the minimum source extent. Inward skin/arc thickness is below half the minimum extent, retains a face and removes actual interior material. Draft is planar, positive up to45degrees, with a different neutral plane perpendicular to local Z. Failures roll back. Unit edits, source updates, Undo/Redo, safe removal, FCStd and STEP preserve supported history. Move the whole Body; member feature placement follows its history. Api PartDesign and the Python console expose the original module. Other modes, arbitrary pull axes, variable radii, patterns, Gui and full workbench qualification remain pending. Android1.15 execution is not yet verified.

1.16 · Original Body patterns
BodyMirror BODY NAME XY|XZ|YZ
BodyLinear BODY NAME COUNT EXTENT_MM X|Y|Z
BodyPolar BODY NAME COUNT ANGLE_DEG X|Y|Z
BodyScaled BODY NAME COUNT FACTOR

Start from one last owned additive Pad/Revolution/AdditiveLoft, with up to64faces/256edges. Patterns use original Features mode and whole original Body origin axes/planes. Counts include the original and are bounded2–16 before recomputation. Linear is one forward total extent; Polar is forward total angle up to360degrees; Scaled grows from1 to a factor greater than1 and at most4 about the native source centre. Copies must form one connected solid. Spacing, second directions, multiple sources, subtractive/dress-up/pattern sources and other modes remain pending.

For a10mm rectangular Pad occupying x0–10/y0–10/z0–10: BodyMirror Body Mirrored XZ gives2000mm3; on separate identical Bodies BodyLinear Body Linear 2 8 X gives1800, BodyPolar Body Polar 4 360 Z gives4000, and BodyScaled Body Scaled 2 2 gives8000. These are native unions, not summed overlapping volumes. Set Linear.Length 1 cm, Set Polar.Angle 270 deg, Set Scaled.Factor 3 and Set Linear.Occurrences 3 update original features. Tip/history/source updates/rollback/FCStd/STEP are supported. Physical Android1.16 execution remains unverified.

NATIVE EXTRUSION EXTENTS (1.17)
Pad Body Profile ReversePad 10 reverse
Pad Body Profile SymmetricPad 10 symmetric
Pocket Body CutProfile ReverseCut 4 reverse
Pocket Body CutProfile SymmetricCut 8 symmetric
PocketThrough Body CutProfile Through forward
PocketFace Body CutProfile Stopped Face5 forward

Use a separate unused owned sketch for each feature; the examples are alternatives. Pad grows along the sketch normal, Pocket cuts opposite it; reverse flips that direction. Symmetric uses half the total length on each side. Through-all uses original FreeCAD Type=ThroughAll and cuts in the selected direction; place the sketch on or beyond the entry face. Face stopping uses original UpToFace on one planar face of the preceding owned Body solid, parallel to the sketch plane and ahead in the cut direction. Inspect source FaceN with ElementInfo before cutting. The native face link stays in the feature history; topology changes can invalidate it and are rejected. Both cuts must retain one valid solid and remove material.
Set Length with units for length extents. Set Reversed true/false for one-sided extents; invalid/no-removal direction edits roll back. Through/face extents have no editable Length. Two sides, taper, offset, custom vectors, curved stopping faces, UpToFirst/Last/Shape, Pad face stopping and arbitrary external stopping references remain pending.
